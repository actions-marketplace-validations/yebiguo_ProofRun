# Contributing

ProofRun is young and the scope is deliberately narrow — read [AGENTS.md](AGENTS.md) first; it's the actual source of truth for how changes are made here, not just guidance for AI agents.

If you're proposing anything that touches STALE detection, the receipt schema, or signature verification: open an issue first. Those are the parts this project can least afford to get wrong.

For anything else: fork, branch, open a PR. Include what you actually tested, not just "tests pass" — this project exists because that sentence isn't good enough on its own.
